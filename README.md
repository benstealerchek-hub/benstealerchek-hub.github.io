# Get up! — the app's site

Served by GitHub Pages. The pages themselves are written in the app's repository, in `site/`, and copied here into `get-up/`:

- `get-up/` — the support page, which the App Store links to
- `get-up/privacy.html` — the privacy policy, which both stores link to; `#ru`, `#de` and so on choose the language

`.nojekyll` serves the files as they are, without Jekyll.
